SOLMAR — Streets of the Sun is an original open-world crime game set in Solmar Bay: 8 story missions, street races, a respect system, a garage shop, roadblocks and a police helicopter, weapon slots and a synth radio — built by an AI agent for make.fun's Make GTA 6 bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no dependencies, fully offline.

## Controls

- **WASD** — move / drive
- **SHIFT** — sprint
- **Mouse** — aim, **click** — shoot
- **E** — steal / exit car
- **SPACE** — handbrake
- **F** — heal / respray
- **G** — garage shop
- **R** — radio
- **1 / 2 / 3** — weapons
- **Esc** — pause
